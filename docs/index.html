Climate Brain v1.3.3

Stamps a Home Assistant package for communicating HVAC zones. Occupancy is any on/off sensor. Travel is optional. Tesla is never occupancy.

Temperature vocabulary (Comfort / Eco / Boost / Away) is inspired by Versatile Thermostat. Climate Brain writes the HVAC climates directly. Attributes: GrokAI.

House

One brain writes every zone. Same occupancy, vacation, Boost, and comfort. Each zone has its own climate entity and night sliders. Cap is 8. Humidity is not used for setpoints, so it is not on this form.

Presence

Climate Brain does not create occupancy. You paste an existing Home Assistant binary_sensor that is on when anyone is home and off when the house is empty. Do not use a car or Tesla.

  1. In Home Assistant: Settings → Devices & services → Helpers → Create helper.
  2. Choose Group → Binary sensor group (if you already have on/off presence sensors), or Template → Binary sensor.
  3. Name it Home occupancy. After save, the entity ID is usually binary_sensor.home_occupancy.
  4. Template example (People → each person entity): {{ is_state('person.you','home') or is_state('person.partner','home') }}
  5. Confirm in Developer tools → States that it flips on/off when you leave and arrive. Paste that entity ID below.

Suggested name: binary_sensor.home_occupancy. Tap Use default only if you already created a helper with that ID.

Travel / arrival precool (optional)

Skip this if you only use occupancy. Then Phase 2 stays off. If you want precool, each traveler needs a direction entity whose state contains toward when heading home, and a travel-minutes entity. Leave the entity boxes empty and paste IDs from Developer tools → States. Use default only fills a suggested name (you still have to create those sensors in HA). iOS is not required.

Temperatures (°F)

Occupied / night / late hold use heat_cool dual setpoints. Empty, Boost, vacation, and precool use one latched heat or cool target.

Clock (local time)

Sleep, morning wake, and day-start are yours. Zone 2 can wake earlier than Zone 1. These become input_datetime helpers so you can still tweak them in HA.

Vacation

The helper always exists in the package. If you skip the button, leave it off. Vacation on = empty-house setpoints until someone is really home.
