How to remove extra thermostats (delete the extra controllers, not the HVAC itself):

  1. Delete Versatile Thermostat / VTherm devices and helpers for these zones. Turning them off is not enough if they start again after a restart.
  2. Delete automations, scripts, Node-RED flows, and helpers that call climate.set_temperature, climate.set_hvac_mode, or climate.set_preset_mode.
  3. Remove Generic Thermostat, Dual Smart Thermostat, or Better Thermostat if they wrap the same equipment.
  4. In the HVAC app (Trane Home / Nexia): turn off Auto and weekly schedules. When people are home, use heat_cool, never Auto.
  5. Keep the climate.* zone entities. If two programs both change the thermostats, the house will bounce between temperatures.

Climate Brain v1.4.1

This page builds a Home Assistant file that controls your heating and cooling. Occupancy is any on/off sensor that means “someone is home.” Travel (phones or Tesla) is optional. A Tesla is never used to decide if the house is occupied.

Names like Comfort, Eco, Boost, and Away are inspired by Versatile Thermostat. Climate Brain talks to the HVAC climates itself. It does not install VTherm. Credit: GrokAI.

House

Use a temperature sensor from your HVAC or from weather (Met.no, OpenWeather, AccuWeather). A weather.* entity works too; Climate Brain reads its temperature. Suggested: sensor.outdoor_temperature or weather.home.

One Climate Brain controls every zone. They share occupancy, vacation, Boost, and comfort. Each zone still has its own thermostat entity and night temperatures. Maximum is 8 zones. Humidity is not used, so it is not on this form.

Heat vs cool is still one choice for the whole house. One outdoor unit should not heat one zone and cool another at the same time.

Who is home

Climate Brain does not make this sensor for you. Paste a Home Assistant binary_sensor that is on when anyone is home and off when the house is empty. Use people or phones, not a car or Tesla.

  1. In Home Assistant go to Settings → Devices & services → Helpers → Create helper.
  2. Pick Group → Binary sensor group if you already have on/off presence sensors. Or pick Template → Binary sensor.
  3. Name it Home occupancy. After you save, the ID is usually binary_sensor.home_occupancy.
  4. Template example using People: {{ is_state('person.you','home') or is_state('person.partner','home') }}
  5. In Developer tools → States, check that it turns on when you arrive and off when you leave. Paste that ID below.

Suggested ID: binary_sensor.home_occupancy. Tap Use default only if you already made a helper with that exact ID.

Travel / start cooling or heating before you arrive (optional)

Skip this if you only care about who is home. Then arrival precool stays off. If you want the house ready before you get there, each traveler needs two sensors: one whose state includes toward when they are heading home, and one for minutes left. Leave the boxes empty and paste IDs from Developer tools → States. Use default only types a suggested name. You still have to create those sensors in Home Assistant. An iPhone is not required.

Travelers

Tesla (optional, travel only)

A Tesla is only used to guess that someone is on the way home. It never counts as “someone is in the house.” Do not add a car to the occupancy sensor.

  • If the car is at home (driveway), that is inhome. Not travel.
  • If navigation is set to home and minutes-to-arrival is a real number, that is toward home.
  • If navigation is set somewhere else, that is away.
  • If no destination is loaded (you know the way), Climate Brain watches whether the car is getting closer to home. About 80 meters closer counts as toward. Farther counts as away.
  • Precool never starts while someone is already home.

Skip this section if Tesla is not in Home Assistant.

Suggested: home, or a street name from the Tesla destination sensor. Do not put Tesla in occupancy.

Vehicles

Temperatures (°F)

When people are home, at night, or in a late-arrival hold, Climate Brain uses heat and cool together (two temperatures). When the house is empty, in Boost, on vacation, or in precool, it uses one heat or one cool target, not both.

Clock (local time)

Set bedtime, morning wake, and when daytime starts. Zone 2 can wake earlier than Zone 1. These become time helpers, so you can still change them in Home Assistant later.

Vacation

The vacation switch always exists in the package. If you hide the dashboard button, leave that switch off. Vacation on uses the empty-house temperatures until someone is really home.

Chaos checker

This test runs after you click Generate. It checks a short occupancy flicker vs a real leave, unknown occupancy never switching to Away, travel toward/away, and outdoor 64 / 65 / 66. Do not install the file if the checker says FAIL.

Click Generate to run the checker.
