Climate Brain v1.3.3

Stamps a Home Assistant package for communicating HVAC zones. Occupancy is any on/off sensor. Travel is optional. Tesla is never occupancy.

House

One brain writes every zone. Same occupancy, vacation, Boost, and comfort. Each zone has its own climate entity and night sliders. Cap is 8.

Presence

Climate Brain does not care how you decide someone is home. Pass any binary_sensor that is on when people are home and off when the house is empty: iOS, Android Companion, a Person group, BLE, alarm panel, or a template you already maintain. Do not OR cars into it.

Travel / arrival precool (optional)

Skip this if you only use occupancy. Then Phase 2 stays off. If you want precool, each traveler needs a direction entity that contains toward when heading home, and a travel minutes entity. That can be iCloud3 on iPhone, Android Companion + a template, OwnTracks, GPSLogger, or anything else. The package never assumes iOS.

Travelers

Temperatures (°F)

Occupied / night / late hold use heat_cool dual setpoints. Empty, Boost, vacation, and precool use one latched heat or cool target.

Vacation

The helper always exists in the package. If you skip the button, leave it off. Vacation on = empty-house setpoints until someone is really home.
